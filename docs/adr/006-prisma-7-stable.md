# ADR-006: Prisma 7.10.1 (stable), not 8.0 RC

**Status:** Accepted · 2026-11-23

## Context

npm's `latest` dist-tag for `prisma` points at `8.0.0-rc.34`, a prerelease. `@prisma/client`'s `latest` is 7.10.1.
The project forbids prerelease dependencies.

## Decision

- `prisma`, `@prisma/client` and `@prisma/adapter-pg` pinned to **7.10.1**.
- Prisma 7 architecture: the `prisma-client` generator outputs CommonJS TypeScript to
  `libs/database/src/generated/prisma` (git-ignored, regenerated by the `prisma-generate` Nx target and `postinstall`).
  `prisma.config.ts` holds schema/migration paths and the datasource URL. The runtime uses the `pg` driver adapter.
- Hand-written SQL (CHECK constraints, triggers) is appended to generated migrations. The migration
  itself is the source of truth for those objects.

## Consequences

Re-evaluate Prisma 8 when it ships as stable. Every Nx target that compiles database code depends on
`prisma-generate`, so a fresh clone builds without manual steps.
